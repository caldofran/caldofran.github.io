# Contributing

Work is tracked through GitHub Issues and pull requests.

- One issue, one branch, one pull request.
- Use branch names like `feat/<issue>-<slug>`, `fix/<issue>-<slug>`,
  `content/<issue>-<slug>`, or `chore/<issue>-<slug>`.
- Keep ownership tight: content changes in YAML, visual changes in CSS/components,
  platform changes in workflows.
- PRs must include the linked issue, evidence, commands run, and PDF artifact when
  PDF or layout changes are involved.
- Merge with squash and delete the branch.
